# Library Management System

## 1. Introduction
The Library Management System is a mini project developed using C++. It helps manage books in a library.

## 2. Features
- Add a new book
- Display all books
- Search for a book
- Issue a book
- Return a book
- Manage book availability

## 3. Technologies Used
- Programming Language: C++
- IDE: Visual Studio Code
- Compiler: GCC (G++)

## 4. Project Files
- main.cpp – Main source code
- books.txt – Book data storage
- library.exe – Executable file
- README.md – Project documentation

## 5. How to Compile

Open the terminal in the project folder and enter:

```bash
g++ main.cpp -o library.exe
```

## 6. How to Run

```powershell
.\library.exe
```

## 7. Conclusion
This project helps understand object-oriented programming concepts and basic library management operations using C++.
